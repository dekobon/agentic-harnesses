# Agentic Security Harnesses
This is a list of all the agentic harnesses that I can find.

- [Anthropic Defending Code Reference Harness (unmaintained) - Skills for threat modeling, scanning, triage, patching, plus an autonomous scanning harness you can /customize](https://github.com/anthropics/defending-code-reference-harness)
- [Semgrep Fork Defending Code Reference Harness (unmaintained) - Skills for threat modeling, scanning, triage, patching, plus an autonomous scanning harness you can /customize](https://github.com/semgrep/defending-code-harness)
- [OpenAI Deep Security Scan - Skill for Codex for doing security scans](https://github.com/openai/plugins/tree/main/plugins/codex-security/skills/deep-security-scan)
- [VulnHunter - Agentic AI security tool that applies proactive, attacker-first analysis directly to source code](https://github.com/capitalone/vulnhunter)
- [Visa Vulnerability Agentic Harness — Agentic SAST Pipeline](https://github.com/visa/visa-vulnerability-agentic-harness)
- [SHERPA - Security Harness Engineering for Robust Program Analysis](https://github.com/AIxCyberChallenge/sherpa)
- [🐍 MEDUSA - AI Security Scanner](https://github.com/Pantheon-Security/medusa)
- [scone-bench - benchmark for evaluating LLM agents on smart-contract vulnerability discovery and exploitation](https://github.com/anthropics/scone-bench)
- [Cloudflare Security Audit Skill - Claude Code skill implementing a 6-phase audit: recon, parallel hunt by attack class, adversarial validation, report, schema-validated findings.json, independent verification](https://github.com/cloudflare/security-audit-skill)
- [Trail of Bits Skills - ~40 plugins for Claude Code and Codex; deep coverage of native code, cryptography (constant-time, zeroize) and smart contracts, emitting SARIF 2.1.0](https://github.com/trailofbits/skills)
- [Google Mantis - ~15 security-focused skills, intended as a starting point rather than a rigid set of instructions](https://github.com/google/mantis)
- [Raptor - Maximalist Claude Code-fronted platform combining Semgrep, CodeQL, AFL++ fuzzing, Z3 exploit feasibility, SCA and multi-model consensus, with loadable expert personas](https://github.com/gadievron/raptor)
- [Vercel DeepSec - Web/app-stack focused pipeline: regex prefilter, AI investigation loop, revalidation pass, plus a --diff mode for PR review](https://github.com/vercel-labs/deepsec)
- [Cisco AI Deep SAST - LLM triage of Semgrep findings across 30+ languages; can run fully local using a security-tuned 8B model](https://github.com/cisco-open/ai-deep-sast)
- [ai-vuln-harness - Community 15-stage Project Glasswing / Cloudflare-methodology pipeline where only the hunt and validate stages call LLMs](https://github.com/daedalus/ai-vuln-harness)
- [Atlantis (Team Atlanta) - 1st place AIxCC finals cyber reasoning system; ensemble-first design with multiple independent bug-finding modules and eight patching agents](https://github.com/Team-Atlanta/aixcc-afc-atlantis)
- [Buttercup (Trail of Bits) - 2nd place AIxCC finals CRS; deterministic workflows with LLMs used only where traditional tools fall short, with a standalone laptop-scale version](https://github.com/trailofbits/afc-buttercup)
- [RoboDuck (Theori) - 3rd place AIxCC finals CRS; full pipeline to proofs-of-vulnerability without fuzzing or symbolic execution (archival, unsupported)](https://github.com/theori-io/aixcc-afc-archive)
- [OSS-CRS - Locally deployable framework for running and combining AIxCC CRS techniques against real open-source projects; the Atlantis port found 10 previously unknown bugs across 8 OSS-Fuzz projects](https://arxiv.org/pdf/2603.08566)
- [Awesome AI Hacking Agents - Index of all seven AIxCC finalist CRSs (incl. FuzzingBrain, ARTIPHISHELL, BugBuster, Lacrosse) and other agentic security tools](https://github.com/EvanThomasLuke/Awesome-AI-Hacking-Agents)
- [Comparing Open-Source AI Code Security Harnesses - Semgrep's July 2026 survey categorizing harnesses into LLM-led exploitgen, LLM-skill-boosting, and SAST+LLM hybrids, with capability matrices](https://semgrep.dev/blog/2026/comparing-open-source-ai-code-security-harnesses)
- [Codebadger - https://github.com/lekssays/codebadger](https://github.com/lekssays/codebadger)
